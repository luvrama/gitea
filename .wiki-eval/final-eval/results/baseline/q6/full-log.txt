[38;5;252m[1m### The Permission Resolution Algorithm[0m[0m
[0m[0m
[1mFile:[22m [38;5;10mmodels/perm/access/repo_permission.go:394-495[0m — [38;5;10mGetIndividualUserRepoPermission[0m[0m[0m
[0m[0m
[38;5;10mStep 1: Load repo units
Step 2: Anonymous + private repo → AccessModeNone (deny)
Step 3: Check if user is a collaborator (collaboration table)
Step 4: Check owner visibility (HasOrgOrUserVisible)
         └─ If owner is private org/user AND user is not collaborator → AccessModeNone
Step 5: Anonymous + public repo → AccessModeRead
Step 6: Site admin OR repo owner → AccessModeOwner
Step 7: Look up access table (collaborator + team combined mode)
Step 8: If owner is an organization:
         a. Set min access = Read for public repos (non-restricted users)
         b. Query GetUserRepoTeams (teams user belongs to that have access to this repo)
         c. If no teams → return current access
         d. If user is collaborator → seed unitsMode with current access for all units
         e. If user is in Owner team → AccessModeOwner (full access)
         f. Otherwise → compute per-unit access as max(collaborator, minAccess, teamUnitMode)
Step 9: finalProcessRepoUnitPermission:
         - Apply anonymous access modes (unit.AnonymousAccessMode)
         - Apply everyone access modes (unit.EveryoneAccessMode)
         - Remove units user has no access to from the permission's unit list

[38;5;252m[1m### The [38;5;10maccess[0m Table (Pre-Computed Permissions)[0m[0m
