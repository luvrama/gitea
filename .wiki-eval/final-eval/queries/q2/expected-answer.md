# Complete Webhook Event Type Addition & Delivery Pipeline

## Full Pipeline Trace: Event Trigger → Delivery

1. Event occurs (e.g., issue created, code pushed)
2. Service calls notify_service.XxxEvent() 
3. notify_service dispatches to all registered Notifiers (including webhookNotifier)
4. webhookNotifier.XxxEvent() constructs API payload struct
5. webhookNotifier calls PrepareWebhooks() with EventSource + event type + payload
6. PrepareWebhooks() collects all applicable webhooks (repo + owner + system)
7. For each webhook, PrepareWebhook() is called:
   a. Checks setting.DisableWebhooks
   b. Checks w.HasEvent(event) against webhook's subscribed events
   c. Checks branch filter via checkBranchFilter()
   d. Serializes payload to JSON via p.JSONPayload()
   e. Creates HookTask record in DB (INSERT into hook_task table)
   f. Enqueues task ID to hookQueue (queue name: "webhook_sender")
8. Queue worker handler() picks up task ID
9. handler() calls webhook_model.GetHookTaskByID()
10. handler() calls Deliver(ctx, task):
    a. Fetches Webhook by ID from DB
    b. Selects Requester function based on webhook Type
    c. Builds HTTP request (type-specific or newDefaultRequest)
    d. Adds headers (X-Gitea-Event, X-Gitea-Event-Type, signatures, etc.)
    e. Adds Authorization header (decrypted from HeaderAuthorizationEncrypted)
    f. Marks task as delivered (MarkTaskDelivered - optimistic lock)
    g. Sends HTTP request via webhookHTTPClient
    h. Records response status/headers/body
    i. Updates HookTask in DB (UpdateHookTask)
    j. Updates Webhook.LastStatus (UpdateWebhookLastStatus)
