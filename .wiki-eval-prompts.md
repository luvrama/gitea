# Wiki Eval Prompts — Gitea (Cross-cutting API analysis)
# Questions that require scanning multiple files across the codebase.

List all API endpoints related to repository management. For each, provide: HTTP method, URL path, handler function, file location, and what authentication/permissions are required.
If I need to add a new webhook event type, what files across routers, services, and models need to change? Trace the full webhook delivery pipeline.
What is the complete data flow when a user creates a pull request via the API? Trace from the HTTP handler through services, git operations, notifications, and database writes.
What are all the external services called during a repository fork operation? List every network call, timeout configuration, and error handling for each.
If I change the user table schema to add a "department" field, list every API endpoint, service, model, and DTO that references the user entity.
Document the complete permission checking chain for the repository API. How does a request go from authentication through org membership, team permissions, collaborator checks, to the final allow/deny?
What are all the API endpoints that trigger git operations? For each, list the git command executed, timeout configured, and what happens on failure.
Map the complete notification system: what events trigger notifications, how are they stored, and which API endpoints serve them? List every file involved.
If the database connection pool is exhausted, which API endpoints are affected and how do they handle it? Trace the error propagation path.
List every API endpoint that performs file I/O operations (reading/writing to disk). What happens to each endpoint if the filesystem becomes read-only?
